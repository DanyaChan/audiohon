# Audiohon

Слушалка аудиокниг в браузере. Книги, прогресс, закладки и коллекции хранятся локально в браузере, без сервера и без загрузки файлов в интернет.

## Запуск

```sh
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/, статический сайт без бэкенда
npm test           # тесты парсеров и сборки оглавления
```

## Что умеет

- **Локальная библиотека.** Аудиофайлы, обложки, прогресс, скорость, закладки и коллекции лежат в IndexedDB. localStorage для аудио не подходит: туда помещается всего несколько мегабайт строк. Прогресс сохраняется каждые 5 секунд, при паузе и перемотке. Дополнительно он синхронно дублируется в localStorage, поэтому не теряется, даже если сразу закрыть вкладку. Последняя открытая книга восстанавливается при следующем визите.
- **Перемотка назад при паузе.** По умолчанию 3 с, настраивается от 0 до 30 с. Срабатывает при любой паузе: кнопкой, пробелом, с наушников, с экрана блокировки, по таймеру сна. Работает и на границе файлов: если книга разбита на части, перемотка уходит в предыдущий файл.
- **Оглавление.** Главы берутся из M4B/M4A (QuickTime chapter track и Nero `chpl`), из ID3v2-тегов MP3 (`CHAP`) и из CUE-файлов. Если глав нет, главой считается каждый файл. Книга из нескольких файлов воспроизводится как единая шкала времени. Для русских тегов и CUE в cp1251 кодировка определяется автоматически.
- **Коллекции.** Их можно создавать, переименовывать и удалять. Книга может входить в несколько коллекций. Добавить книгу можно через меню книги, через диалог коллекции или перетащив карточку на коллекцию в боковой панели. Кроме того, есть автоматические разделы «Слушаю», «Новые» и «Прослушано».
- **Плеер.** Скорость 0,5–3× (запоминается для каждой книги), кнопки перемотки на 15/30 с (настраиваются), переход по главам, таймер сна (по времени или до конца главы), закладки с заметками. Поддерживается Media Session API: управление с экрана блокировки, из уведомлений и медиаклавишами.
- **Импорт.** Можно выбрать файлы или папку либо перетащить их в окно. Перед добавлением видно, как файлы разобьются на книги (одна книга, по папкам, по файлам), и можно поправить название и автора. Обложка берётся из `cover.jpg`/`folder.jpg` рядом с книгой или из тегов.
- Горячие клавиши: пробел — пауза, ←/→ — перемотка, Shift+←/→ — главы, `[`/`]` — скорость, `B` — закладка.
- Две открытые вкладки не мешают друг другу: при старте воспроизведения другая вкладка встаёт на паузу, а прогресс синхронизируется.

## Устройство

| Путь | Что там |
| --- | --- |
| `src/player/player.ts` | Движок воспроизведения: один `<audio>` на все файлы книги, сквозная шкала времени, перемотка при паузе, сохранение прогресса, таймер сна, Media Session |
| `src/store/library.ts` | Состояние библиотеки (книги, прогресс, закладки, коллекции) и запись в IndexedDB |
| `src/lib/db.ts` | Схема IndexedDB (через `idb`) |
| `src/lib/metadata/` | Парсеры тегов и глав: MP4/M4B, ID3, CUE, определение кодировки |
| `src/lib/import/` | Разбор выбранных файлов, группировка в книги, построение оглавления, сохранение |
| `src/components/` | Интерфейс на React |

Стек: Vite, React 19, TypeScript. Тестовые аудиофайлы для парсеров пересоздаются командой `npm run fixtures`, нужен ffmpeg.

Данные живут в конкретном браузере. Если очистить данные сайта или открыть его в режиме инкогнито, библиотека будет пустой. В настройках можно попросить браузер не удалять данные при нехватке места (`navigator.storage.persist()`).
